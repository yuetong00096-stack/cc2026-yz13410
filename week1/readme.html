"Creative Coding Is..."

For this assignment, I chose eight definitions because I think they show that creative coding is not just writing code to make visual effects. Before reading these definitions, I thought creative coding might be more about making images, animations, or interactive things with code. But these definitions made me think about it in a wider way. To me, creative coding is not only using code as a tool. It is more like treating code as a creative medium. Code can run, generate, change, and create something that is not fully visible before it is executed. This is very different from normal coding. Normal coding is usually about finishing a function, solving a problem, or making software work correctly. Creative coding also needs logic and precision, but its purpose is not only function. It is also about process, expression, and artistic experience. One point I found interesting is that the meaning of code does not only stay in the written code itself. The meaning appears more clearly after the code runs. When code is executed, it can become movement, sound, image, interaction, or a system that keeps changing. So creative coding is not just about the final result. The action of running the code is also part of the work.
